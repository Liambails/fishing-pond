# COBALT V3.10.10 — Observer-safe opportunity intelligence

COBALT's own Playwright listing-detail visits may contribute to marketplace view counters.

V3.10.10 records successful Playwright detail-page observations and subtracts possible COBALT-originated views from observed view gains before using those gains as demand evidence.

The correction is deliberately conservative:

external_view_delta_lower_bound =
max(0, raw_view_delta - possible_cobalt_views)

Historical periods without explicit observer telemetry are not retroactively corrected.

Opportunity qualification now also has an explicit live-state rule:

- metrics.currently_qualified === true => live
- status === sourcing => live regardless of current qualification
- currently_qualified false or missing => not live unless manually sourcing

This prevents legacy opportunity rows and stale pre-correction SOURCE_NOW records from contaminating the live sourcing inbox while preserving historical records.
