# COBALT V3.10.14 — Bulk Search Term Builder

Search Terms now supports a single search/add field and CSV bulk import for scaling discovery terms.

## Single-term behavior
Typing filters the existing table immediately. Pressing Add/Enter creates the exact term only when it is not already present. Duplicate comparison is case-insensitive and collapses whitespace; duplicates are silently ignored.

## CSV import
Use the upload icon beside Add. The modal provides a CSV template. The only required header is:

```csv
search_term
```

Add one marketplace query per subsequent row, e.g. a vehicle model + chassis code. Blank rows and duplicate rows are ignored. The server performs a second duplicate check against existing Search Terms before inserting.

New imports retain the normal defaults: Trade Me, six-hour cadence, three result pages, 100 rows/page, active immediately and due on the next scheduler opportunity.
